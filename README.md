# Pédagogie et didactique à l'école primaire — carte mentale (CRPE)

Carte mentale interactive des techniques didactiques et pédagogiques, organisée par questions du métier : concevoir une séance (dont ABC Learning Design), que faire de l'erreur, différencier, évaluer, rendre les élèves actifs (pédagogies actives), apprendre à l'école maternelle, et les débats.

En ligne : https://laetitiaperez.github.io/pedagogie-didactique/

Chaque nœud indique son niveau de source (texte officiel, ressource institutionnelle, formation ou mouvement pédagogique, repère académique) et cite les documents avec la page du PDF. Chaque méthode a un encadré « En classe » (maternelle et élémentaire) : les exemples tirés d'un document sont cités, les autres sont marqués « Piste ».

## Vérifier les citations

Les PDF et leurs textes extraits sont rangés dans `sources/` (non versionné). `node verif-citations.mjs` contrôle que chaque citation figure à la page indiquée.
